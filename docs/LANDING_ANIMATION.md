# Star → people, boat and flower

The approved final artwork is `public/studies/flat-figures-flower-v3.svg`. Its original upright figures, extended left foot and boat are preserved in `intro-art.ts`. The final flower is a larger asymmetric red/coral bloom with a yellow cushion and cream Malayalam അ outline. Design work and visual checks are desktop-only by user preference.

The original keyword prelude (Letters / Sounds / Words / അക്ഷരം) and opposing crossing stars return in a compact 1.65-second opening. Then one cream star expands with unequal red/coral/yellow stars and grows into the final flat illustration. The white silhouette uses 241 baked SVG boundary contours. It no longer uses automatic vertex correspondence: a signed-distance surface expands outward while the recesses open, keeping limbs from flipping through each other. The exact approved paths replace the sampled contour at the end. Colored star layers use one uninterrupted GSAP MorphSVG interpolation into the asymmetric flower while the central letter forms; no intermediate ease-out/ease-in stop. There is no regular six-petal intermediate shape. The morph runs 15% faster (about 4.17 seconds); the entire sequence including the restored prelude takes about 5.82 seconds. Two text lines flow left to right on open waves entirely below the boat, and is static under reduced motion. Its natural phrase width sets the repeat distance without stretching Malayalam glyphs.

`intro-motion.ts` owns the prelude and a nested morph timeline, and renders white contours in the timeline update callbacks. Consumers must preserve that callback if adding progress UI. Replay explicitly permits timeline callbacks at time zero. Skip, replay, keyboard focus isolation and reduced-motion final state are covered by interaction tests. The development-only slider supports frame inspection; production retains Replay, Skip animation and Start.

`intro-growth-frames.ts` is generated by `scripts/design/generate-intro-growth.py`. Authoring dependencies: Python with numpy, scipy, Pillow and contourpy. They are not browser/runtime dependencies. Regenerate only after changing approved geometry or intermediate shape design. Browser runtime uses SVG, React and the existing GSAP dependency.

Validation: existing test suite and targeted intro interaction tests, TypeScript, production build, static export verification, and desktop frame-by-frame review. Replay, reduced-motion final state and the exact approved final paths are verified.

Local app: `npm run dev`, then `http://localhost:3000/aksharam/#intro`. A self-contained animation preview is also provided outside the repo as `../aksharam-morph.html`.

The second wave quotes the first two lines of Kumaran Asan’s public-domain poem വീണ പൂവ് (1907). Source: https://ml.wikisource.org/wiki/Veena_Poovu . The first wave reads LEARN TO READ MALAYALAM. Start is enlarged and anchored at bottom right.
